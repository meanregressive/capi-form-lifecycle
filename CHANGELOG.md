# Changelog - capi-form-lifecycle skill

## 0.1.0 - 2026-09-18
- First public version: four modes (build, patch, diff, paper), five references, six scripts (extract_for_diff, validate_xlsform, build_diff_docx, paper_from_xlsform, pdf_to_docx, xlsform_io).
- Starter example's Round-1 form is built on SurveyCTO's basic template (`example/_template/empty_instrument.xlsx`, linked from the DIME Wiki), keeping its 31 type-coloring rules and help sheets.
- `xlsform_io.py`: edits carry workbook formatting (fills, fonts, widths, hidden columns, freeze panes, conditional formatting, data validation, tab color) by field name; validator WARNs when a patched file lost formatting vs `--base`.
- Instrument argument resolves against the brief's register by number, short name or full name.
- Translation handling and data-access rules are brief-level decisions, not hard-coded.
- `example/`: fictional starter project generated by `_generate_example.py`; `run_checks.py` doubles as the test suite.
- Versioning rule: `version` always increases; `form_id` changes only by decision (new data stream).
